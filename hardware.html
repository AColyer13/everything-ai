Hardware

How fast each kind of AI hardware really is, measured by memory bandwidth, and the best job each one can do: NVIDIA B200, RTX 5080, DGX Station, DGX Spark, Apple M5 Ultra, M5 Max and M6.

Not from the class

This page is a reference added on top of the course content. Specs are a snapshot from November 2026 taken from vendor pages and secondary coverage, and some are rumors (marked below). Speeds shown are theoretical ceilings; real-world results are typically about half. The models these machines run, and the software, are on the Models and Tools pages.

Why bandwidth sets the speed

When an LLM writes text it generates one token at a time, and for every token the chip must read the model's active weights out of memory. So the generation speed is limited mainly by memory bandwidth, not raw compute:

tokens per second  ≈  memory bandwidth (GB/s)  ÷  GB of weights read per token
  • A dense 70B model at 4-bit reads about 40 GB per token. At 273 GB/s that is at most about 7 tokens per second.
  • A mixture-of-experts model with about 6B active parameters reads only about 3.5 GB per token at 4-bit, so the same chip can be many times faster.
  • Capacity decides whether the model fits at all. Compute decides how fast the machine reads a long prompt (prefill). Bandwidth decides how fast it writes the answer (decode).

What the table teaches

Two things beat raw size: a mixture-of-experts model (reads far fewer weights per token) and more bandwidth. The 16 GB RTX 5080 has more bandwidth than the 128 GB DGX Spark, so it is faster on anything that fits, but the Spark can load models the 5080 cannot.

The best each can do

NVIDIA B200

  • Speed: about 8 TB/s per GPU, the fastest here by a wide margin, and eight of them in a server are linked by NVLink.
  • Best at: training large models, and serving the biggest models to thousands of users at once with high throughput. It is also the best single chip for prompt processing.
  • Limits: not a desktop product, very expensive, usually rented by the hour from a cloud. See the enterprise table on the Models page.

NVIDIA DGX Station

  • Speed: data-center class bandwidth (HBM around 7 to 8 TB/s) in a desk-side machine, with a big pool of slower CPU memory behind it.
  • Best at: running or fine-tuning very large models (hundreds of billions of parameters) at full speed, and serving a whole team from one box with the full CUDA stack.
  • Limits: priced like a server, far above the others. Models that spill from HBM into the CPU memory slow down to about 400 GB/s.

Apple M5 Ultra (Mac Studio)

  • Speed: about 1.2 TB/s, roughly 50% above the M3 Ultra it replaces. Apple announced it in August 2026 with the 512 GB configuration said to arrive in late October; I did not confirm that it has shipped.
  • Best at: the most memory per dollar. It loads huge models (hundreds of billions of parameters at 4-bit) in one quiet machine and runs mixture-of-experts models at comfortable speeds.
  • Limits: slower than NVIDIA at prompt processing and training, and software built only for CUDA will not run.

Apple M5 Max

  • Speed: about 614 GB/s, the 128 GB configuration (the 32-core GPU version has less memory and bandwidth).
  • Best at: a portable machine that runs models in the 30B to 120B range at 4-bit. Mixture-of-experts models in the 100B class run well; dense 70B is usable but slow.
  • Limits: half the bandwidth and a quarter of the memory of the M5 Ultra.

NVIDIA RTX 5080 (16 GB)

  • Speed: about 960 GB/s (256-bit GDDR7; this figure is from the card's specification rather than the sources I searched), faster than the DGX Spark and the M5 Max.
  • Best at: models that fit in 16 GB: Gemma 4 12B QAT, gpt-oss-20b, and 7B to 14B models, all fast. Strong at image generation, and at prompt processing for its price.
  • Limits: only 16 GB. Anything larger spills into slower system RAM, as with Qwen3.8-Flash-Next through Strata.

NVIDIA DGX Spark

  • Speed: about 273 GB/s, the slowest generation here after the base M6.
  • Best at: fitting a 100B-class model in 128 GB with the full CUDA stack, and fine-tuning and development work where the model matters more than tokens per second. Two units can be linked for 256 GB.
  • Limits: dense large models generate slowly because of the bandwidth. Mixture-of-experts models are the good fit.

Apple M6 (base chip)

  • Status: reported by Bloomberg's Mark Gurman and other outlets for late 2026 in a MacBook Pro, built on a 2 nm process. Reports of its bandwidth disagree: about 200 GB/s in most, 170 GB/s in two. Treat everything here as unconfirmed.
  • Not a big-model chip: reports say Apple does not plan M6 Pro, Max or Ultra variants and expects bigger chips to follow with the M7 family, so the M6 is the entry-level chip.
  • Best at (if it matches reports): small models in the 1B to 14B range on a laptop. Do not plan on running big models on it.

Buy for the model you want to run

Start from the model: its size at 4-bit decides the memory you need, whether it is dense or mixture-of-experts decides the bandwidth you need, and your tolerance for slow prompt processing decides Apple versus NVIDIA.
