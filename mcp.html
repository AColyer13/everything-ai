MCP

The Model Context Protocol (MCP) is the standard way an AI app connects to outside tools and data: your files, Google services, a brokerage account, a database. This page covers where it came from, how it works, example connectors, and how to use them safely.

About this page

Connectors and their rules change often, so treat the details as a snapshot from November 2026 and check each provider's own documentation before connecting anything.

Where MCP came from

Anthropic introduced MCP on 25 November 2024 as an open standard. The problem it solved: every AI app needed its own custom integration for every data source, so connecting N apps to M tools meant N times M separate pieces of glue. With MCP, a tool is wrapped once as an MCP server, and any app that speaks the protocol can use it. People often compare it to a USB-C port for AI.

WhenWhat happened
25 Nov 2024Anthropic open-sources the specification and SDKs, adds MCP support to the Claude desktop app and publishes reference servers for tools such as Google Drive, Slack and GitHub. Early adopters named in coverage include Block and Apollo, and the developer tools Zed, Replit, Sourcegraph and Codeium.
2025Other major AI vendors, including OpenAI, Google and Microsoft, add MCP support to their products, and thousands of community servers appear.
9 Dec 2025Anthropic donates MCP to the Agentic AI Foundation, a fund under the Linux Foundation co-founded by Anthropic, Block and OpenAI. Anthropic says the governance model stays the same, with maintainers continuing to lead decisions.

How it works

PartRoleExample
Host / clientThe AI app that wants to use outside toolsClaude, Claude Code, ChatGPT, Cursor, an app you build
ServerA small program or web service that exposes a tool or data source in the MCP formatA GitHub server, a BigQuery server, a Robinhood server
ToolsActions the model can ask for, such as "run this query" or "create this issue"list_accounts, run_query
ResourcesRead-only data the app can pull in as contextA file, a database table, a document
PromptsReusable prompt templates a server offers"Summarize this repo's open pull requests"
  • Local servers run on your own computer and talk to the app directly. They are common for files and developer tools.
  • Remote servers are web services at a URL. You add the URL in the app's settings (often called a "custom connector"), and a sign-in page opens in your browser. You log in there, never in the chat.
  • The model never gets direct access. It asks, the app calls the server, and the app can ask you to approve each action first.

Using connectors safely

Rules of thumb

Use the provider's own official server, grant the least access you can, begin read-only, and keep approval on for anything that spends money, sends messages or deletes things.

  • Official over third-party. Search results for popular services include unofficial servers, some of which ask for your email and password. Never hand a login to a server the provider does not run. Real remote servers sign you in on the provider's own page.
  • Prompt injection. Anything a tool returns (an email, a web page, a document) is data, but a model may treat text hidden in it as an instruction. The more tools connected at once, the larger the risk, so connect only what the task needs.
  • Money and markets. A connector that can trade moves real money. Use a dedicated account with a small balance, turn on trade approvals and review the activity feed. This page is not financial advice.
  • Review before approving. Read what an action will do before you click allow, especially writes, sends and deletes.
  • Audit. Remove connectors you no longer use and check which apps still hold access.

When to use MCP

Use it when...Skip it when...
The model needs live data it cannot know, such as your database, calendar or repoPasting the text into the chat is enough
You want one integration reused across several AI appsYou only need one simple script that calls one API
You want the model to take actions, with approval, in other systemsThe action is high-risk and no approval step exists
