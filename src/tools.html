Tools

Seven AI tools you will run into (Claude, Grok, Cursor, Antigravity, ChatGPT, OpenClaw and OpenCode), plus two open-model resources: Hugging Face and Unsloth. What each one is, where you can use it, and when to pick it.

About this page

These products change every few months (names, plans, models, even who owns them), so treat the details as a snapshot from November 2026 and check each maker's own site before relying on them. Prices are deliberately left out.

At a glance

Two words matter here. A web app is a chat you open in a browser. A CLI (command-line interface) is a program you run in a terminal, where it can read your files, run commands and edit code on your computer. Many tools now offer both.

Claude

Made by: Anthropic. Type: assistant and coding agent, available as both a web app and a CLI.

  • Web app: claude.ai in the browser, plus desktop and mobile apps. Chat, upload documents and images, and work on longer pieces such as code, documents and small web pages.
  • CLI: Claude Code runs in your terminal (command claude). It reads your project, edits files, runs tests and commands, and can open commits and pull requests, asking permission for risky steps. The workflow Anthropic recommends (Explore, Plan, Code, Commit) is on the Loops page.
  • API: developers call the models from their own code, as in the Generative AI page.
  • Good for: careful writing, long documents, code changes across a whole repository, and tool-using agents.
  • Watch out: like every LLM it can state wrong things confidently. Review what it writes, especially code it ran or changed.

Grok

Made by: xAI. Type: assistant and coding agent, available as both a web app and a CLI.

  • Web app: grok.com and inside X (formerly Twitter), where it can use live posts as context.
  • CLI: Grok Build is xAI's official terminal coding agent (command grok). It launched in beta in mid-May 2026 for SuperGrok Heavy subscribers, and secondary coverage reports a 1.0 release on 7 August 2026 that works with SuperGrok, X Premium+ or an API key (check x.ai/cli for current access). It plans multi-step work, edits files and runs commands, and can run headless in scripts. The command is grok and the source is public under the Apache-2.0 licence.
  • Not the same thing: a community project also called grok-cli exists. Its own README says it is not affiliated with xAI. Make sure you install the one you mean.
  • Good for: questions about current events and social media, and trying a different model family for coding.
  • Watch out: access tiers and features have changed quickly since launch, and our sources are secondary coverage, so check xAI's own pages.

Cursor

Made by: Anysphere, which SpaceX agreed to buy in June 2026 for about $60 billion in stock. Coverage based on an SEC filing says the deal closed on 14 August 2026 (one outlet says 15 August). Type: an AI-first code editor (a fork of VS Code).

  • What it is: an editor that looks and feels like VS Code, so your extensions and keybindings carry over, with AI built into every part: autocomplete, chat about your code, and an agent that edits many files at once.
  • Agents: it can run several agents in parallel, and cloud agents can keep working in the background. It also offers its own models and a code-review bot (Bugbot).
  • CLI: the Cursor CLI runs the same coding agent in a terminal, interactively or headless in scripts and CI. Guides disagree on the command name (agent or the older cursor-agent), so check Cursor's docs.
  • Good for: people who prefer working inside an editor with visual diffs over a terminal.
  • Watch out: ownership changed in 2026 (see above) and plans and pricing change often, so check Cursor's site for current information.

Antigravity

Made by: Google. Type: agentic development platform, with a desktop app and a CLI (plus an SDK and the original IDE).

  • Desktop app and IDE: a workspace where several agents take on programming tasks in parallel and report back.
  • CLI: the terminal version is agy. According to coverage of the May 2026 launch, it replaces Google's earlier Gemini CLI (consumer access ended in June 2026; enterprise Gemini Code Assist licenses are kept) and shares the same engine as the desktop app.
  • SDK: lets developers build their own agents on the same foundation.
  • Good for: splitting a large coding job across several agents, especially if you already use Google's Gemini models.
  • Watch out: most of what is written about it is secondary coverage. Check Google's own pages for model support and pricing.

ChatGPT

Made by: OpenAI. Type: general-purpose assistant, as a web app and mobile and desktop apps.

  • What it is: the chat assistant that brought large language models to the mainstream, launched in November 2022. It writes, summarizes, explains, analyzes files, generates images, and can browse the web and run code.
  • For coding: OpenAI has a separate agent, Codex, that also comes as a CLI. It is a different product from the ChatGPT chat window.
  • Good for: everyday questions, drafting, brainstorming and learning a topic.
  • Watch out: do not paste confidential or personal data into any tool you do not control. See the responsible-AI notes on the Generative AI page.

OpenClaw

Made by: created by Peter Steinberger as an open-source project; he joined OpenAI in February 2026 and the project is reported to be moving to an open-source foundation. Type: a self-hosted personal AI agent you talk to through chat apps.

  • What it is: a program that runs on your own computer or server and connects an AI model to your files and your messaging apps (such as Telegram, WhatsApp, Discord, Slack or Signal), so you can message it and it carries out tasks.
  • Bring your own model: it works with cloud models (Claude, GPT) or local open models. The software is free; you pay for the model usage.
  • Name history: it spread quickly under the name Clawdbot, was renamed Moltbot in January 2026, and then became OpenClaw. Several outlets credit Peter Steinberger as its creator.
  • Good for: a "do things for me from my phone" assistant that you control.
  • Watch out: because it runs locally with broad access to your files and accounts, security is the main concern. Limit what it can reach, and read the project's own safety notes before you connect real accounts.

OpenCode

Made by: Anomaly (open source). Type: an open-source terminal coding agent.

  • What it is: a coding agent with a full-screen terminal interface (run opencode inside a project folder). It reads and edits code and runs commands, like Claude Code, but is open source (MIT licensed according to coverage).
  • Any model: it connects to many providers, including Claude, OpenAI, Google and local models, so you can switch models without switching tools. It is also available as a desktop app and an IDE extension.
  • Good for: people who want an open tool that is not tied to one vendor.
  • Watch out: star and user counts differ across sources, and at least one directory mislabels it as an Anthropic product. Use the official opencode.ai site.

Hugging Face

Made by: Hugging Face. Type: platform and libraries for open models, datasets and demos. It is not an assistant itself.

  • The Hub: huggingface.co hosts millions of public model repositories plus datasets and "Spaces" (small hosted demo apps). Most open models on the Models page, such as Qwen and Gemma, are published there, and a model ID like Qwen/Qwen3.5-9B is simply the account and repository name.
  • Libraries: transformers loads and runs models in Python, datasets loads data, and huggingface_hub (with its command-line tool) downloads and uploads files. The fine-tuning pipeline relies on them.
  • Model cards and licences: every repository has a card describing the model, its licence and its limits. Some models are "gated", which means you accept the terms and sign in with an access token before downloading.
  • Good for: finding open models and datasets, downloading weights for Ollama, LM Studio or vLLM, and sharing your own.
  • Watch out: anyone can upload, so check who published a model, prefer well-known publishers, and read the licence. Avoid running unknown scripts from a repository, and keep your access token private.

Unsloth

Made by: Unsloth AI. Type: open-source toolkit for fine-tuning and running open models, with a Python library and a local web app.

  • Library: makes fine-tuning faster and lighter on memory, which is what lets a single 16 GB GPU train models like those in the fine-tuning pipeline. The project claims about 2 times faster training and around 70% less VRAM with no loss in accuracy; those are its own figures.
  • Unsloth Studio: a local, no-code web interface to run, train and export models. Coverage says it launched in March 2026. The GitHub repo is Apache-2.0 with an AGPL-3.0 licence file for the Studio parts, so check the licence before building a product on it.
  • Quantized releases: Unsloth publishes ready-made GGUF versions of popular models on Hugging Face (its "dynamic" quantizations keep important layers at higher precision). Strata's README lists several of them. See the quantization section on the Models page.
  • Guides: its documentation has model-specific advice, for example its caution against 4-bit QLoRA on Qwen3.5.
  • Good for: fine-tuning on a single consumer GPU, and downloading small, well-prepared GGUF files.
  • Watch out: speed and memory claims come from the project, and model-specific advice changes with each release.

Ollama

The easiest developer route: install it, run ollama run <model>, and it downloads and serves the model. Many coding agents (including OpenCode) can use it as their backend. Good default for a laptop or a single GPU.

LM Studio

A desktop app with a model browser, chat window and a local server. It shows whether a model will fit your memory before you download, and on Apple Silicon it can use MLX for faster generation. Best if you prefer clicking to typing commands.

vLLM

Built for throughput. Techniques such as continuous batching and paged KV-cache memory let one GPU server answer many requests at once. Use it when you serve a team or an application, not for casual chatting. It expects a Linux GPU box such as a DGX system.

Strata

A free, open-source engine from an individual developer, built to run large mixture-of-experts models on a consumer PC by spreading them across GPU memory, system RAM and SSD. Its README lists Qwen3.8-Flash-Next (125B), Qwen3.6-35B-A3B and DeepSeek V4.1-Flash. Its reported speeds depend heavily on context length, quantization and RAM, and the first launch can load tens of gigabytes. It is best understood as a specialist for models too big for your memory, not a replacement for Ollama or vLLM. Details come from project-reported figures and secondary coverage.

Which one?

Start with LM Studio or Ollama. Move to vLLM when you need to serve many users. Try Strata only if you specifically want a model too large for your VRAM, such as the 125B Qwen model, on a gaming PC.

The tool matters less than the loop

Whichever tool you pick, results come from the same habits: a clear goal, a way to check the output (tests, a rubric), small steps, and a human review. The Loops page lists the patterns, and Finetuning an LLM and Creating an LLM cover the models underneath.
