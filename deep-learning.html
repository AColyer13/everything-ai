Deep Learning

Deep learning uses neural networks with many layers to learn features directly from raw data such as pixels, audio and text. It powers modern vision, speech and language systems.

Why deep learning, and when

Classical ML needs you to design features by hand. Deep networks learn their own features, which is why they dominate images, audio and language. The price is that they need lots of data, lots of compute and careful tuning.

Classical MLDeep learning
Best forTabular data, small to medium datasetsImages, audio, text, very large datasets
FeaturesEngineered by youLearned by the network
ComputeCPU is usually enoughGPU recommended
ExplainabilityOften easyHarder

The field took off in the last decade through three things arriving together: big datasets, GPUs, and better training tricks. Typical applications are image recognition, translation, speech assistants, recommendations, medical imaging and self-driving perception. Challenges include data hunger, cost, overfitting, bias in data, and black-box behaviour.

The perceptron and how networks learn

A perceptron is one artificial neuron: multiply each input by a weight, add a bias, and pass the sum through an activation function.

z = w1*x1 + w2*x2 + ... + b
output = activation(z)
ActivationShapeTypical use
SigmoidSquashes to 0..1Binary output probability
TanhSquashes to -1..1Older recurrent nets
ReLUmax(0, z)Default for hidden layers
SoftmaxProbabilities that sum to 1Multi-class output

Without activation functions, stacking layers would collapse into one linear function. A single perceptron can only draw a straight boundary, so it cannot solve problems like XOR; hidden layers remove that limit.

Training in four repeating steps

  1. Forward propagation: push inputs through the layers to get a prediction.
  2. Loss: measure how wrong it was.
  3. Backpropagation: use the chain rule to work out how much each weight contributed to the error (its gradient).
  4. Update: nudge each weight against its gradient, scaled by the learning rate. Repeat over many epochs.

Loss functions

TaskLoss
RegressionMean squared error, mean absolute error
Binary classificationBinary cross-entropy
Multi-class classificationCategorical cross-entropy

TensorFlow and Keras

TensorFlow works on tensors (n-dimensional arrays). Keras is its friendly model-building layer. Use the Sequential API for a simple stack of layers and the Functional API for branches, multiple inputs or outputs. TensorFlow Playground is a free browser tool for building intuition on tiny networks.

import tensorflow as tf
from tensorflow import keras

model = keras.Sequential([
    keras.layers.Input(shape=(20,)),
    keras.layers.Dense(64, activation="relu"),
    keras.layers.Dropout(0.3),
    keras.layers.Dense(32, activation="relu"),
    keras.layers.Dense(1, activation="sigmoid"),
])
model.compile(optimizer="adam", loss="binary_crossentropy", metrics=["accuracy"])
history = model.fit(X_train, y_train, validation_split=0.2, epochs=50, batch_size=32,
                    callbacks=[keras.callbacks.EarlyStopping(patience=5, restore_best_weights=True)])

Optimizers

An optimizer decides how to use the gradient. They build on each other:

OptimizerKey idea
SGDStep downhill using a small batch of data at a time
MomentumKeep a running velocity so steps smooth out and roll through flat spots
AdagradGive rarely-updated parameters bigger steps
Adadelta, RMSPropAdapt step sizes using a moving window of recent gradients, fixing Adagrad's ever-shrinking steps
AdamMomentum plus RMSProp. The usual first choice

Making training work

  • Batch normalization rescales each layer's inputs, which speeds training and tolerates higher learning rates.
  • Vanishing and exploding gradients: in deep nets gradients can shrink to nothing or blow up. ReLU, careful weight initialization, normalization, residual connections and gradient clipping help.
  • Dropout randomly switches off neurons during training so the network cannot lean on any one of them. Early stopping halts training when validation loss stops improving.
  • Hyperparameter tuning: learning rate, batch size, depth, width and dropout rate. Try a random or Bayesian search before an exhaustive grid.
  • Interpretability: tools such as SHAP, LIME and saliency maps show which inputs drove a prediction.

Convolutional neural networks (CNNs)

CNNs are built for images. Instead of connecting every pixel to every neuron, small filters slide across the image and detect local patterns such as edges, then textures, then object parts in later layers. Filters are shared across the image, which cuts parameters dramatically.

LayerDoes
ConvolutionApplies filters to produce feature maps
Pooling (max or average)Shrinks the maps and adds tolerance to small shifts
Flatten and denseTurns features into a final decision
cnn = keras.Sequential([
    keras.layers.Input(shape=(64, 64, 3)),
    keras.layers.Conv2D(32, 3, activation="relu"), keras.layers.MaxPooling2D(),
    keras.layers.Conv2D(64, 3, activation="relu"), keras.layers.MaxPooling2D(),
    keras.layers.Flatten(), keras.layers.Dense(128, activation="relu"),
    keras.layers.Dense(10, activation="softmax"),
])

ResNet-50 is a famous deep CNN that uses skip connections so gradients flow through 50 layers. TensorBoard plots training curves so you can see over- and underfitting.

Transfer learning

Instead of training from scratch, start from a model pretrained on a huge dataset (for example ImageNet) and adapt it. Freeze the early layers, which already know edges and shapes, and train a new final layer on your small dataset. Benefits: far less data and compute, and usually better accuracy. Pick a pretrained model that matches your task and image size, and check its licence.

base = keras.applications.ResNet50(weights="imagenet", include_top=False, input_shape=(224, 224, 3))
base.trainable = False
model = keras.Sequential([base, keras.layers.GlobalAveragePooling2D(), keras.layers.Dense(5, activation="softmax")])

Object detection and edge deployment

Classification says what is in an image; object detection also says where, by predicting bounding boxes. YOLO ("you only look once") does this in a single pass, which makes it fast enough for video. Preparing the dataset means labelling boxes for each object. For phones and embedded devices, TensorFlow Lite converts a trained model into a smaller, faster format.

Sequence models: RNNs

Some data is ordered: text, speech, sensor readings. A recurrent neural network reads one step at a time and carries a hidden state forward as memory. Training uses backpropagation through time. Plain RNNs forget over long spans because of vanishing gradients, which is why LSTM and GRU cells with gates were invented. Hybrid models combine a CNN to read each frame with an RNN to read the sequence, as in video classification.

Transformers and BERT

Transformers replaced recurrence with self-attention: every token looks at every other token and decides how much to weigh it. That captures long-range context and trains in parallel on GPUs.

  • Architecture: an encoder stack, a decoder stack, positional encoding (so order is known), multi-head attention and feed-forward layers.
  • BERT uses only the encoder and reads text in both directions. It is pretrained, then fine-tuned for classification, question answering and search.
  • Decoder-style transformers are the basis of large language models. See Generative AI.

Autoencoders

An autoencoder squeezes its input through a narrow bottleneck (the encoder) then rebuilds it (the decoder), trained to make the output match the input. The bottleneck is forced to hold the essence of the data. Uses: compression, denoising, anomaly detection (bad reconstruction means unusual input) and pretraining.

PyTorch

PyTorch builds the computation graph as your code runs, which makes debugging feel like normal Python. You write the model as a class and the training loop yourself.

import torch, torch.nn as nn

class Net(nn.Module):
    def __init__(self):
        super().__init__()
        self.net = nn.Sequential(nn.Linear(20, 64), nn.ReLU(), nn.Linear(64, 1))
    def forward(self, x):
        return self.net(x)

model, loss_fn = Net(), nn.BCEWithLogitsLoss()
opt = torch.optim.Adam(model.parameters(), lr=1e-3)

TensorFlow or PyTorch?

Both are fine. Keras gets you a working model in fewer lines; PyTorch gives more control and is common in research. Concepts transfer completely, so learn one well first.
