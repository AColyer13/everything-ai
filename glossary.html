Glossary

Plain-English definitions. Type in the box to filter.

Activation function
A function applied to a neuron's weighted sum that lets a network model non-linear patterns. Common ones: ReLU, sigmoid, tanh, softmax.
Agentic AI
An AI system that plans and carries out multi-step tasks using tools, with limited human intervention.
API key
A secret string that identifies you to a service. Keep it in an environment variable, never in shared code.
Attention
A mechanism that lets a model weigh how relevant each part of the input is to every other part. The core of transformers.
Autoencoder
A network that compresses data into a small code and rebuilds it. Used for denoising, compression and anomaly detection.
Backpropagation
The method that computes each weight's gradient by applying the chain rule backwards through the network.
Bagging
Training many models on random resamples of the data and averaging them to reduce variance. Random forest is the best-known example.
Batch normalization
Rescaling a layer's inputs during training so learning is faster and more stable.
Bayes' theorem
A rule for updating a probability when new evidence arrives: P(A|B) = P(B|A)·P(A) / P(B).
BERT
A transformer encoder that reads text in both directions. Pretrained, then fine-tuned for tasks like classification and question answering.
Bias (data)
Systematic skew in training data that leads a model to treat groups unfairly or make skewed predictions.
Bias (model)
Error from a model being too simple to capture the real pattern (underfitting).
Boosting
Training models in sequence, each correcting the previous one's errors. Examples: AdaBoost, gradient boosting, XGBoost.
Broadcasting
NumPy's rule for combining arrays of different shapes without copying data.
Central Limit Theorem
The averages of many samples tend toward a normal distribution regardless of the original distribution.
Chi-square test
A test for relationships between categorical variables, or whether data fits an expected distribution.
Classification
Predicting a category, such as spam or not spam.
Clustering
Grouping similar points without labels. K-means and hierarchical clustering are common methods.
CNN (convolutional neural network)
A network that slides small filters over images to detect patterns from edges up to objects.
Cold start
A recommender's difficulty with new users or items that have no history.
Collaborative filtering
Recommending by using the behaviour of many users, such as people with similar tastes.
Confidence interval
A range built so that it contains the true value in a stated share of repeated samples.
Confusion matrix
A table of true and false positives and negatives for a classifier.
Context window
How much text a language model can consider at one time.
Correlation
A measure from -1 to 1 of how strongly two variables move together. It does not prove causation.
Cross-validation
Splitting training data into folds and rotating which fold is held out, to estimate performance reliably.
Data drift
A change in the inputs a deployed model sees compared with training data.
Data leakage
When information from the test set or the future sneaks into training, making results look better than they are.
Decision tree
A model that predicts by following a series of yes/no questions.
Diffusion model
A generator that starts from noise and removes it step by step to produce an image. Stable Diffusion is one.
Dimensionality reduction
Representing data with fewer features while keeping most of the information. PCA is the classic method.
Dropout
Randomly switching off neurons during training to reduce overfitting.
Early stopping
Ending training when validation performance stops improving.
Embedding
A vector of numbers that captures the meaning of a word, sentence, image or item.
Ensemble
A combination of several models whose joint prediction beats any single one.
Epoch
One full pass through the training data.
Eigenvector / eigenvalue
A direction that a matrix only stretches (the vector) and the stretch factor (the value). The basis of PCA.
Euclidean distance
The straight-line distance between two points.
Federated learning
Training across many devices where raw data stays local and only model updates are shared.
Few-shot prompting
Including a few worked examples in a prompt so the model imitates the pattern.
Fine-tuning
Continuing to train a pretrained model on your own data for a specific task or style.
Gradient
The direction and rate of steepest increase of a function. Training follows its negative.
Gradient descent
Repeatedly stepping against the gradient to reduce error.
Hallucination
A fluent but false statement produced by a language model.
Hyperparameter
A setting you choose before training, such as learning rate, tree depth or number of clusters.
Hypothesis testing
A procedure for deciding whether data provides enough evidence against a default assumption (the null hypothesis).
JSON
A text format of key-value pairs and lists used by most web APIs. Maps closely to Python dictionaries.
K-means
A clustering algorithm that repeatedly assigns points to the nearest centre and moves each centre to the mean of its points.
k-nearest neighbors
A model that predicts from the labels of the k closest training points.
L1 / LASSO
Regularization that can shrink some coefficients to exactly zero, performing feature selection.
L2 / Ridge
Regularization that shrinks all coefficients smoothly toward zero.
LLM Wiki
Andrej Karpathy's pattern in which an LLM builds and maintains a set of interlinked Markdown pages from your raw sources (ingest, query, lint), so knowledge accumulates instead of being re-retrieved for every question.
Learning rate
How big a step the optimizer takes each update.
LLM (large language model)
A very large transformer trained on text to predict the next token. It can write, summarize, translate and code.
Loss function
A number measuring how wrong the model's predictions are. Training tries to minimize it.
LSTM
A recurrent cell with gates that lets networks remember information over long sequences.
MLOps
The practice of deploying, monitoring and retraining machine learning models reliably.
Normal distribution
The symmetric bell-shaped distribution that describes many natural measurements.
Null hypothesis
The default assumption that nothing interesting is happening, which a test tries to reject.
Object detection
Finding and labelling objects in an image with bounding boxes. YOLO is a fast approach.
Outlier
A point far from the rest of the data.
Overfitting
When a model memorizes training noise and performs poorly on new data.
p-value
The probability of data at least this extreme if the null hypothesis were true. Small values are evidence against it.
PCA (principal component analysis)
A method that finds the directions of greatest variance and projects data onto the top few.
Perceptron
A single artificial neuron: weighted sum plus bias, passed through an activation.
Precision
Of the items predicted positive, the share that really are.
Prompt engineering
Writing instructions for a model so the output is accurate, well formatted and cheap to produce.
Prompt injection
Hostile text that tries to override a model's instructions. Treat outside text as untrusted.
RAG (retrieval-augmented generation)
Supplying a model with relevant passages from your own data at question time, so answers are grounded and current. It rebuilds its understanding from scratch for each question; see LLM Wiki for the alternative.
Random forest
An ensemble of decision trees trained on random subsets, averaged for a robust prediction.
Recall
Of all truly positive items, the share the model found.
Regression
Predicting a number, such as a price.
Regularization
A penalty or constraint that discourages overly complex models to reduce overfitting.
Reinforcement learning
Learning to act by trial and error, guided by rewards.
ReLU
The activation max(0, x). The default choice for hidden layers.
ResNet
A deep CNN using skip connections so very deep networks can train.
RNN
A network that processes sequences one step at a time, carrying a hidden state as memory.
Sampling settings
Controls such as temperature, top_p, top_k and repeat penalty that change how a language model picks each next token.
Self-attention
Attention where every token in a sequence weighs every other token in the same sequence.
SGD
Stochastic gradient descent: update weights using one example or a small batch at a time.
Sigmoid
An S-shaped function mapping any number to between 0 and 1.
SMOTE
A technique that creates synthetic examples of the minority class to balance a dataset.
Softmax
Turns a list of scores into probabilities that sum to 1.
Stacking
An ensemble where a final model learns how to combine other models' predictions.
Supervised learning
Learning from examples that include the correct answer.
SVD
Singular value decomposition: factoring a matrix into simpler pieces. Used in PCA and recommenders.
SVM
Support vector machine: a classifier that finds the widest-margin boundary between classes.
Temperature
A setting controlling how random a language model's output is.
Tensor
An n-dimensional array of numbers, the basic data structure in TensorFlow and PyTorch.
Token
A small piece of text (a word or part of one) that a language model reads and writes.
top_p / top_k
Filters on the next-token choice: top_k keeps the k likeliest tokens, top_p keeps the smallest set whose probabilities sum to p.
Transfer learning
Reusing a model pretrained on a large dataset as the starting point for a new task.
Transformer
A neural architecture built on self-attention that underlies BERT and modern LLMs.
Type I error
Rejecting a null hypothesis that is actually true (a false alarm).
Type II error
Failing to reject a null hypothesis that is actually false (a miss).
Underfitting
When a model is too simple to capture the pattern and performs poorly even on training data.
Unsupervised learning
Finding structure in data without labels.
Vanishing gradient
When gradients shrink toward zero in deep networks, so early layers barely learn.
Variance
How spread out values are. In modelling, error from being too sensitive to the training data (overfitting).
YOLO
"You only look once": a fast object detector that predicts boxes and classes in one pass.
Zero-shot prompting
Asking a model to do a task with an instruction only and no examples.
