# Everything AI

A static study-guide website built from the Microsoft AI Engineer program.

- Open `index.html` in any browser (no server needed), or upload the folder to any static host (GitHub Pages, Netlify, OneDrive/SharePoint).
- Edit the content in `src/*.html`, then run `python build.py` to regenerate the pages and the search index.
- Styles are in `assets/style.css`; the page script is `assets/app.js`.
