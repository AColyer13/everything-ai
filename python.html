Python

Python is the default language of AI because it reads almost like English and has a library for nearly everything. This page covers the parts of the language you will use every day.

Getting set up

You need three things: a Python interpreter, an editor or IDE, and a way to install packages. For data work, Jupyter Notebook is the usual choice because you can run code in small cells and see results immediately.

python --version
pip install numpy pandas matplotlib scikit-learn jupyter
jupyter notebook
Habit worth building

Use a virtual environment per project (python -m venv .venv) so one project's package versions never break another's.

Types, variables and operators

Python is dynamically typed: a variable takes the type of the value you assign. The core types are int, float, str, bool, and the collections list, tuple, set and dict.

Strings

Strings are immutable sequences. Slice them with s[start:stop:step], and use f-strings for formatting. Methods like .split(), .strip(), .replace() and .join() cover most cleaning jobs.

Decisions and loops

score = 72
if score >= 90:
    grade = "A"
elif score >= 70:
    grade = "B"
else:
    grade = "C"

for i in range(5):           # 0..4
    if i == 3:
        continue             # skip this pass
    if i == 4:
        break                # leave the loop
    print(i)

n = 0
while n < 3:
    n += 1
else:
    print("loop finished without break")   # runs only if no break

break exits the loop, continue skips to the next pass, and the lesser-known else block on a loop runs only when the loop was not stopped by break.

Functions

A function packages reusable logic. Give it clear inputs and a return value rather than printing inside it.

def describe(name, age=30, *tags, **extra):
    """Positional, default, variable-length (*) and keyword (**) arguments."""
    return f"{name} ({age}) tags={tags} extra={extra}"

describe("Ada", 36, "ml", "math", city="London")

Scope

Python looks for a name in this order: Local, Enclosing, Global, Built-in. Assigning inside a function creates a local variable unless you declare global or nonlocal. In practice, pass values in and return results out.

Generators, lambdas and comprehensions

def squares(n):              # generator: yields one value at a time
    for i in range(n):
        yield i * i

evens = [x for x in range(20) if x % 2 == 0]       # list comprehension
lookup = {w: len(w) for w in ["ai", "data"]}       # dict comprehension
by_len = sorted(["aaa", "b", "cc"], key=lambda s: len(s))

Generators matter for large data because they produce values lazily instead of building the whole list in memory.

Object-oriented programming

A class is a blueprint and an object is one instance of it. Libraries like scikit-learn and PyTorch are built from classes, so reading them gets much easier once this clicks.

class Account:
    def __init__(self, owner, balance=0):
        self.owner = owner
        self._balance = balance        # leading underscore: "treat as private"

    def deposit(self, amount):
        if amount <= 0:
            raise ValueError("amount must be positive")
        self._balance += amount

    @property
    def balance(self):
        return self._balance

class Savings(Account):                # inheritance
    def add_interest(self, rate):
        self.deposit(self._balance * rate)
PillarMeaning
EncapsulationKeep data and the methods that change it together, and control access to it
InheritanceA child class reuses and extends a parent class
PolymorphismDifferent classes respond to the same method name in their own way
AbstractionExpose a simple interface and hide the details behind it

Python has no strict private members. A single underscore signals "internal" and a double underscore triggers name mangling.

Threads

Threads let a program do several things at once, which helps when work spends its time waiting, such as network calls or file reads. Because of the Global Interpreter Lock, threads do not speed up CPU-heavy Python code in the standard build; use multiprocessing for that. (Newer Python versions offer an optional free-threaded build that removes this limit.)

import threading, time

def work(n):
    time.sleep(1)
    print("done", n)

threads = [threading.Thread(target=work, args=(i,)) for i in range(3)]
for t in threads: t.start()
for t in threads: t.join()      # wait for all of them (synchronization)

lock = threading.Lock()         # protect shared data
counter = 0
def bump():
    global counter
    with lock:
        counter += 1

JSON and dictionaries

JSON is how most web APIs send data, and a JSON object maps almost one-to-one onto a Python dictionary. If you understand dictionaries, you already understand JSON. This comes up again on the Generative AI page.

More Python details that get asked

Details

Points that the sections above only touch on.

Basics

  • Identifiers: cannot start with a digit, are case-sensitive, and cannot be keywords. Notebooks use the .ipynb extension. REPL = read-eval-print loop. A missing indent raises IndentationError.
  • Variables are references. id() shows the object's memory address. y = x shares one object; reassigning creates a new one, and += on an immutable value also makes a new object.
  • Conversion: int(45.77) truncates (gives 45, no rounding). int("45.88") fails but float("45.88") works. Spaces around a number are fine, spaces inside are not.
  • Falsy values: 0, False, "", empty list/tuple/dict, and None. Everything else is truthy.
  • input() always returns a string. Convert it with int() or float().
  • Operators: / true division, // floor division (50 // 4 = 12), % modulo, ** power. is / is not compare identity (same object), not value. in / not in test membership and are case-sensitive.
  • Strings: triple quotes make multi-line strings, negative indexes start at -1, and every string method returns a new string.

Loops and range

  • range(stop), range(start, stop) and range(start, stop, step) exclude the stop value. A step cannot be 0, and a negative step needs start > stop. range returns a range object; wrap it in list() to see it.
  • The three loop styles: count-controlled, condition-controlled (while) and collection-controlled (for). A while loop can run zero times, and Python has no do-while. Stop an infinite loop in Jupyter with Interrupt kernel. After a break the loop variable keeps its last value.

Functions

  • Arguments: positional vs keyword. Defaults must come after required parameters. A missing required argument raises TypeError.
  • return: a function with no return gives None, nothing after return runs, and you can return several values (as a tuple).
  • Scope: a local variable can shadow a global one. Reading a global needs no keyword; changing it inside a function needs global.
  • map, filter, reduce: map(f, items) applies f to every item and returns an iterator (wrap in list()). filter(f, items) keeps items where f returns true. reduce lives in functools and folds a sequence to one value: reduce(lambda x, y: x + y, nums). A lambda is an anonymous function with a single expression.
  • Generators: yield pauses and keeps local state (return destroys it). Use next(gen) or a for loop. A generator can be iterated only once.

Object-oriented programming

  • __init__ is the constructor, called automatically when an object is created; self is the instance. Instance attributes belong to one object; a class attribute is shared by all instances (for example an object counter). Python has automatic garbage collection, so you rarely need a destructor (__del__ exists but is seldom used). pass is the placeholder for an empty class.
  • Access levels: public by default, _x protected by convention, __x private (a subclass touching it gets AttributeError).
  • Inheritance types: single, multilevel, multiple and hierarchical. A subclass __init__ replaces the parent's, so call the parent's explicitly (super().__init__()).
  • Polymorphism: run-time (overriding) works. Python does not truly support method overloading (the last definition wins), but operators are overloaded, such as + adding numbers and joining strings.
  • Abstraction: use ABC and @abstractmethod from abc. An abstract class cannot be instantiated (TypeError), and subclasses must implement its abstract methods.

Threads

  • You can subclass threading.Thread and override __init__ and run(). A lock has acquire() and release().
  • Race condition: two threads change shared data at once and the result depends on timing. Locks give mutual exclusion but can cause deadlock if threads wait on each other.
  • Threads are lightweight and share memory. Single operations such as list.append are atomic, but read-modify-write steps such as count += 1 are not, so protect shared data with a lock.
