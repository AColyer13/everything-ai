Data Science

Data science is the craft of turning raw data into decisions. It rests on four skills: fast numerical computing, a little linear algebra, statistical thinking, and clean tabular data you can chart.

The data science process

  1. Frame the question. What decision will this inform, and how will you know it worked?
  2. Collect data. Files, databases, APIs, logs.
  3. Clean and prepare. Missing values, duplicates, wrong types, outliers. This usually takes the most time.
  4. Explore. Summaries and charts to understand distributions and relationships.
  5. Model. Statistics or machine learning to answer the question.
  6. Communicate and monitor. Share results clearly and watch for drift after deployment.

NumPy

NumPy gives you the ndarray, a fixed-type n-dimensional array that runs operations in compiled code. It is far faster than Python lists and is the base of pandas, scikit-learn and the deep learning libraries.

import numpy as np

a = np.array([[1, 2, 3], [4, 5, 6]])
a.shape            # (2, 3): axis 0 = rows, axis 1 = columns
a.sum(axis=0)      # column sums -> [5, 7, 9]
a.mean(axis=1)     # row means   -> [2., 5.]
a[a > 2]           # boolean mask -> [3, 4, 5, 6]
a[:, 1]            # every row, column 1
a * 10             # vectorized: no loop
a.reshape(3, 2)
Axes in one sentence

axis=0 collapses down the rows (you get one value per column); axis=1 collapses across the columns (you get one value per row).

Broadcasting lets arrays of different shapes combine when their trailing dimensions match or equal 1, for example subtracting a column-mean vector from every row of a matrix.

Descriptive statistics

Types of data

Categorical data is nominal (no order, such as colour) or ordinal (ordered, such as small, medium, large). Numerical data is discrete (counts) or continuous (measurements). The type decides which summaries and charts make sense.

Centre and spread

MeasureUse when
MeanData is roughly symmetric with no big outliers
MedianData is skewed or has outliers (income, house prices)
ModeCategorical data, or finding the most common value
Variance, standard deviationHow far values typically sit from the mean
IQRA spread measure that ignores extreme values

Skewness measures lopsidedness (a long right tail is positive skew). Kurtosis measures how heavy the tails are. Covariance shows whether two variables move together, and correlation rescales that to between -1 and 1. Correlation does not prove causation.

Probability and distributions

DistributionModelsExample
BernoulliOne yes/no trialOne coin flip
BinomialNumber of successes in n trialsHeads in 10 flips
PoissonCount of events in a fixed intervalSupport tickets per hour
UniformAll outcomes equally likelyA fair die
NormalMany natural measurements, bell-shapedHeights, measurement error

The probability mass function (discrete) or density function (continuous) says how likely values are; the cumulative distribution function gives the probability of being at or below a value.

The Central Limit Theorem says the averages of many samples form a roughly normal distribution, whatever the shape of the original data. It is why so much of inference works.

Bayes' theorem updates a belief when new evidence arrives: P(A|B) = P(B|A) · P(A) / P(B). It is the idea behind Naive Bayes classifiers.

Hypothesis testing

You start by assuming nothing interesting is happening (the null hypothesis, H0), then ask whether the data is surprising enough to reject that assumption in favour of the alternative (H1).

  • p-value: the probability of seeing data at least this extreme if H0 were true. A small value (commonly below 0.05) is evidence against H0. It is not the probability that H0 is true.
  • Type I error: rejecting a true null (a false alarm). Type II error: failing to reject a false null (a miss).
  • Confidence interval: a range that would contain the true value in a stated share (say 95%) of repeated samples.
TestQuestion it answers
z-testCompare a mean to a value when the sample is large or the variance is known
t-testCompare means when the sample is small and the variance is unknown
Chi-squareAre two categorical variables related? Does data fit an expected distribution?
ANOVA / F-testDo three or more group means differ? Compare variances
from scipy import stats

a = [12.1, 11.8, 12.5, 12.9, 11.5]
b = [13.2, 13.0, 12.8, 13.9, 13.4]
t, p = stats.ttest_ind(a, b)
print(f"t={t:.2f}, p={p:.4f}")

pandas

pandas gives you the Series (one labelled column) and the DataFrame (a table). It is the main tool for loading, cleaning and reshaping data.

import pandas as pd

df = pd.read_csv("sales.csv", parse_dates=["date"])
df.head(); df.info(); df.describe()

df["revenue"] = df["price"] * df["qty"]
df[df["region"] == "West"].sort_values("revenue", ascending=False)
df.groupby("region")["revenue"].agg(["sum", "mean"])
pd.pivot_table(df, values="revenue", index="region", columns=df["date"].dt.month, aggfunc="sum")

Cleaning checklist

  • Nulls: df.isna().sum() to find them; dropna() or fillna() to handle them. Choose by understanding why they are missing.
  • Duplicates: df.drop_duplicates().
  • Types: astype(), pd.to_datetime(), pd.to_numeric(errors="coerce").
  • Binning: pd.cut and pd.qcut turn numbers into ranges.
  • Scaling: normalize to 0-1 or standardize to mean 0 and standard deviation 1 before distance-based models.
  • Joins: pd.merge(left, right, on="id", how="left").
  • Memory: use category dtype for repeated strings and downcast numbers for big files.
From the live classes

Write cleaning code as functions that find columns automatically instead of listing them by hand. For example, flag columns with a single unique value (zero variance, which carry no information), treat columns with few unique values as categorical, and columns with exactly two as binary. Scripts like that keep working when new data arrives.

zero_var = [c for c in df.columns if df[c].nunique() == 1]
binary   = [c for c in df.columns if df[c].nunique() == 2]
categ    = [c for c in df.columns if 2 < df[c].nunique() <= 100]

Regular expressions and databases

Regular expressions find patterns in text: re.findall(r"\d{3}-\d{4}", text). For structured storage, Python's sqlite3 module or pandas.read_sql lets you query a database and get a DataFrame back.

From the lessons

Rules, formulas and defaults the instructors taught that the sections above summarise only briefly.

Levels of measurement

LevelMeaningExample
NominalCategories, no orderColour, city
OrdinalOrdered, gaps not equalSmall / medium / large
IntervalEqual spacing, no true zeroTemperature in Celsius
RatioEqual spacing and a true zeroKelvin, height, price

Sets: sample space (all outcomes), event (a subset), union, intersection and complement.

Shape of a distribution

  • Skewness is 0 for a normal distribution. Negative = longer left tail, positive = longer right tail.
  • Kurtosis is 3 for a normal distribution. Excess kurtosis (kurtosis minus 3) is 0 for normal, positive for heavy tails and outliers, negative for light tails.

Distributions

  • Binomial: P(X = r) = nCr · pr · qn-r with q = 1 - p.
  • Poisson: mean = variance = λ, standard deviation = √λ. Used when there are many opportunities and each is unlikely.

Estimation and confidence

  • A point estimate is one number; an interval estimate is a range. A good estimator is unbiased, has minimum variance (efficient) and is consistent.
  • Confidence level is commonly 95% or 99%. The margin of error is the half-width of the interval; smaller is better.
  • t or z? Use t when n < 30 and the population variance is unknown; use z when n ≥ 30 or the population variance is known. t = (x̄ - μ) / (s / √n); z uses σ in place of s.

Chi-square, F and ANOVA

  • Chi-square goodness of fit is a non-parametric (Pearson) test with df = k - 1. Steps: state hypotheses, choose α (usually 0.05), compute df, apply the decision rule. Reject H0 when p < α. Shapiro-Wilk and Kolmogorov-Smirnov are other goodness-of-fit tests.
  • F-distribution: the ratio of two chi-square variables, each divided by its degrees of freedom. The shape depends on both df, and the order matters: F(6, 8) is not F(8, 6).
  • ANOVA tests whether three or more group means differ. H0: all means are equal; H1: at least one differs. It is an omnibus test, so it does not say which group differs. Assumptions: independent observations, normally distributed residuals, equal variances and a continuous outcome.
  • Partitioning: total variation splits into between-group and within-group (error) sums of squares. F = between-group variance / within-group variance; a large F means the group means differ more than chance would explain.
  • Types: one-way (one factor), two-way (two factors) and N-way (more factors). MANOVA is a separate extension with several outcome variables. A factor has levels; a factor can be fixed or random.

Linear algebra

Vectors are linearly independent when none of them can be written as a combination of the others.

pandas defaults and idioms

  • loc selects by label, iloc by integer position.
  • Statistics skip missing values by default (skipna=True); std uses ddof=1; corr defaults to Pearson. pivot_table defaults to aggfunc="mean".
  • Window functions: rolling and expanding. Dates: DatetimeIndex, date_range and Timedelta.
  • Method chaining ("pandorable" code) strings operations together in one readable expression.
  • Basics worth knowing: lists are mutable, tuples are not; a list comprehension can include an if; statsmodels provides OLS regression with a full summary table.

Chart design (Tufte)

  • Graphical integrity: do not distort the data. Maximize the data-ink ratio and remove chart junk. Prefer high data density and small multiples (many small charts on the same scale) over one cluttered chart.
